# 資料DLランキング（メルマガ生成）WordPressプラグイン

store.f-mikata.jp の Flamingo に溜まった資料ダウンロードの申込を集計し、
人気ランキングのメルマガ本文を作る。

**ミカタ株式会社の資産**。Keys株式会社の案件とは分離すること。

```
fmikata-dl-ranking-wp/
```

## 何をするプラグインか

「資料DLランキング」→「ランキング作成」で期間を選ぶと、2つのランキングを同時に出す。

| | 対象 | 既定の期間 |
|---|---|---|
| ① サービスランキング | 「不動産会社向けサービス一覧」配下の記事 | 先月 |
| ② ノウハウ本ランキング | 「不動産会社向けノウハウ資料」配下の記事 | 先月 |

**どちらに入るかは記事のカテゴリだけで決まる。** 書式ひな形やお役立ちツールなどの
テンプレート類は、どちらの配下にもないので自動的に対象外になる。フォームに残っている
`tags`（売買テンプレート／E-BOOK…）は運用の途中で意味が変わっていて、いまのカテゴリ
構成と一致しないため、判定には一切使っていない。

候補を15件出し、そこから掲載する10件を選んで並べ替える。件数はどちらも設定で変えられる。

- 左が掲載リスト、右が候補。ドラッグでも、↑↓と「載せる／外す」でも動かせる
- 資料名と一言コメントはその場で書き換えられる（一言の初期値は記事の抜粋）
- 本文は HTML とテキストの両方をその場で生成する。コピーして配信システムに貼る
- 「選定内容を保存」を押すと、同じ期間で開き直したとき並びが戻る

## ①が団子になったら期間を延ばす

既定はどちらも先月。ただしサービスは1ヶ月だと母数が薄い。
2026年8月の実測で、対象64件のうち「2件」が8本、「1件」が19本あり、
10位で切ると8位以下は全部同数になる（機械の順序に意味がない）。
その場合は画面で「直近3ヶ月」に切り替えると 41／18／13／12／10／9／8… と差がつく。
ノウハウ本は1ヶ月でも 22／16／14／12／11… と割れる。

どちらにせよ掲載する10件は手で選んで並べ替えるので、期間はあくまで候補の出しかたの調整。

## 集計のしかた

- 1申込＝1件。設定で「同じメールアドレスの重複を除く」に切り替えられる
- 前期間（直前の同じ長さの期間）との比較を各行に出す
- 同数のときは前期間の多い順、それも同じならタイトル順。何度集計しても並びは変わらない
- URL は `https://` `www.` 末尾スラッシュ クエリ を落として突き合わせる

## リリース

```
py build.py 1.0.1 "・○○を修正"
git add -A && git commit -m "v1.0.1" && git push
```

push すると、プラグインを入れたサイトの管理画面に「更新可能」バッジが出る。
更新の置き場は `update.json` の `download_url`（GitHub の raw）。

## 初回の導入

1. `py build.py 1.0.0` で `fmikata-dl-ranking.zip` を作る
2. WordPress の「プラグイン」→「新規追加」→「プラグインのアップロード」で入れる
3. 「資料DLランキング」→「設定」を開き、カテゴリのスラッグと Flamingo のフィールド名が
   緑の表示になっているか確認する（既定値のままで合っているはず）

2回目以降は上の「リリース」だけでよい。手動アップロードは不要。
