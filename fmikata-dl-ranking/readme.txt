Flamingo に溜まった資料ダウンロードの申込を集計し、人気ランキングのメルマガ本文を作ります。

== Description ==

「資料DLランキング」→「ランキング作成」で期間を選ぶと、次の2つのランキングを同時に出します。

* ① サービスランキング … 「不動産会社向けサービス一覧」配下の記事
* ② ノウハウ本ランキング … 「不動産会社向けノウハウ資料」配下の記事

どちらに入るかは記事のカテゴリだけで決まります。書式ひな形やお役立ちツールなどの
テンプレート類は、どちらの配下にもないので自動的に対象外になります。

= 使いかた =

1. 期間を選んで「この条件で集計する」
2. 左が掲載リスト、右が候補。ドラッグ、または ↑↓ と「載せる／外す」で入れ替える
3. 資料名と一言コメントはその場で書き換えられる
4. 本文（HTML／テキスト）が下に出るのでコピーして配信システムに貼る
5. 「選定内容を保存」を押しておくと、同じ期間で開き直したとき並びが戻る

= 集計のしかた =

* 1申込＝1件。設定で「同じメールアドレスの重複を除く」に切り替えられます
* 前期間（直前の同じ長さの期間）との比較を各行に表示します
* 同数のときは前期間の多い順、それも同じならタイトル順で並べます
